4. Audience decision (summary of the memo)

Store: 4+, not Kids Category, general-audience copy ("unhurried", "relaxing", "brain"). Code: child-directed + under-age + General + NPA for everyone (Google says the two tags should not both be true; both are deprecated in favour of ageRestrictedTreatment, which the 8.1.0 bridge does not expose). Privacy label declares tracking that never happens. Recommendation: keep Option A live; prepare Option B (mixed audience with a neutral age screen before SDK init: child / teen / adult treatment, unknown = child); gates are legal judgment on the "directed to children" totality test, bridge API migration, consent-lifecycle tests, label update, product decision. Option C (general audience, no screen) is rejected. No revenue uplift is claimed.
