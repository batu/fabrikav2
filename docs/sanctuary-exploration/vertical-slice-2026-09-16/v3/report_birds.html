Pedestal contract proof: 3 birds × 4 states, placed on tiers 1–3

Each type is one transparent call rendering four states on a shared floor line (plain / accessory / costume / mastered), split into sprites. Houses define pedestals in pedestals.json (anchor, width, facing). Placement = flip to face the door, scale to pedestal width, draw a shared soft contact shadow, drop on the anchor. The bird knows nothing about the house.

The sprite family

3 calls, 12 sprites. Body, face and colours hold across states; the mastered state adds the satchel and a gold star pin.
