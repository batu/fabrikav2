3. Implementation proof: base house + extracted per-slot patches

Left: base tier-3 house. Middle: base + the robin patch cut from the one-bird edit by diff. Right: base + the three patches cut from the three-bird edit. This is the game lane: one base sprite per house tier, one small patch PNG per (tier, slot, bird type, costume state), generated by a masked edit and extracted by diff, layered at runtime. Nothing is pasted; every bird was rendered in place with the house's rim, peg and lighting.

Cost of the lane at scale

3 tiers × 3 slots × 10 types × 4 states = 360 patches ≈ $0.02–0.03 each ≈ $10, one-off. Slots on the same house can be batched into one edit as above.
