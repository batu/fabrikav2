Flow

  1. Home → Collection tile unlocked, Sanctuary tile locked.
  2. Play levels; sparrow pickups fill the active card.
  3. Sparrow reaches Unlocked → Sanctuary opens → Place sparrow (screen 2 → 3).
  4. Coins from levels + the house drip → Upgrade to tier 2 (screen 4) → second pedestal.
  5. Robin unlocks → Place picker (screen 5). Tier 3 + bluebird complete the release loop.
