Find the Bird reaches play 34% faster.

Eleven startup experiments, two explicit startup reversions, two rejected completion densities, a simplification pass, adversarial review, and a final physical iPhone tour produced a faster runtime without changing levels, hitboxes, sprite placement, progression, or the Classic pickup default.

Retained branch verified on iPhone 12

Retain

Ship the runtime branch after normal merge approval. The five-run median composite fell from 5,897.42 ms to 3,865.57 ms. Requests, bytes, and heap growth all moved in the same direction; every benchmark correctness gate passed.

Remaining evidence gap

Physical motion is not yet recorded. The final build passed the device tour and its states were inspected, but stills do not prove pickup, haptic, or confetti timing.

The retained shape is simpler

The speedup came mostly from removing waits and duplicate work. Robustness changes were retained even when their timing stayed inside the declared 120 ms noise band, but only when they removed a demonstrated race or ownership ambiguity.

Critical path

Start useful work sooner

Current-level prewarm begins in the first idle window. Deferred settings and shop art is owned by Home and canceled when play starts. A ready board no longer waits through obsolete cover dwell.

Reuse

Do stable work once

Bundled level data survives scene shutdown, concurrent level-index requests share one in-flight computation, and current-level persistence writes only the field that changed.

Ownership

Make teardown explicit

Blob-backed assets still revoke and rebuild, hidden-page idle work requeues correctly, scene resources have one named release path, and camera sampling no longer allocates an object every frame.

Eleven experiments, no survivor bias

Two startup candidates were reverted because they failed to beat the retained frontier. Four non-metric changes stayed because they reduced traffic, persistence work, allocation, or lifecycle risk under dedicated tests.

Verified, with one honest gap

The exact retained commit was built, installed, toured, inspected, and relaunched on the connected phone. Browser and unit proof covers timing and invariants more deeply; device stills cover physical rendering, not motion.

Known test debt

The unfiltered suite contains one pre-existing stale byte-size assertion in five-square-campaign.test.ts: expected 9,629 bytes, actual 9,628. The same mismatch exists on the base commit. Level content was not altered to appease bookkeeping.
