The bug and the fix

Before

A translated crop box was clamped edge by edge. At a boundary, one edge stopped and the other continued—translation silently became resize.

→
After

The drag delta is clamped once as a unit. The box moves until containment stops it; width and height cannot change.

Simplified

  • Removed unused Wizard modal state and dead view variables.
  • Shared review card state and newest-item comparison.
  • Collapsed duplicate counts and retired CSS.
  • Replaced vague action state with a precise archive-busy flag.

Robustified

  • Abort stale candidate, prompt, and retry requests on session change.
  • Clear prior-session review data immediately.
  • Ignore stale placement responses.
  • Autosave placement without refetching every candidate.
